# openvpn3-indicator-rs

A system tray indicator for [OpenVPN 3 Linux](https://github.com/OpenVPN/openvpn3-linux),
written in Rust. Inspired by the Python
[openvpn3-indicator](https://github.com/OpenVPN/openvpn3-indicator).

> **Status: prototype.** It talks to OpenVPN 3 v27 correctly (configs, sessions, live status),
> shows the tray icon and menu, and has the credentials, import, remove and about dialogs.
> Connect, credentials, import and remove have not been tested against a real VPN server yet.

![icons](docs/icons.png)

## Features

- Tray icon (StatusNotifierItem / AppIndicator) that reflects the state of all sessions
- Menu to connect, pause, resume, restart and disconnect, and to import or remove profiles
- Credentials dialog. Secrets can be stored in the Secret Service (GNOME Keyring / KWallet).
- Opens the browser for web-based authentication (`SESS_AUTH_URL`)
- Desktop notifications on status changes
- Opening `.ovpn` files (`openvpn3-indicator-rs profile.ovpn`, or through the MIME handler) offers to import them
- `--dump` prints what the indicator sees over D-Bus. This is handy for debugging.

## How it talks to OpenVPN 3

No async runtime is used. Everything runs on the GLib main loop that GTK needs anyway:

| Concern | Implementation |
|---|---|
| OpenVPN 3 D-Bus API | [`src/openvpn3.rs`](src/openvpn3.rs): `gio::DBusConnection` with `call_sync` and `subscribe_to_signal` |
| Tray icon + menu | [`ksni`](https://crates.io/crates/ksni) (blocking API; it runs its own D-Bus thread) |
| Dialogs | GTK 4 (`gtk4` crate) |
| Secrets | [`dbus-secret-service`](https://crates.io/crates/dbus-secret-service) (blocking) |
| Notifications | `org.freedesktop.Notifications` through gio |

The services used are `net.openvpn.v3.configuration` and `net.openvpn.v3.sessions` on the system bus.
Session status arrives as `StatusChange` signals once `LogForward(true)` has been called on the session.
On top of that, the state is refreshed every 5 s.

## Installing

Download the `.deb` from the [latest release](https://github.com/skoky/openvpn3-indicator-rs/releases/latest)
(Ubuntu 24.04 or newer, amd64) and install it:

```bash
sudo apt install ./openvpn3-indicator-rs_*_amd64.deb
```

You also need [OpenVPN 3 Linux](https://community.openvpn.net/openvpn/wiki/OpenVPN3Linux).

## Building

Common tasks are recipes in the [`justfile`](justfile); run `just` to list them.

```bash
sudo apt install just
just deps     # apt install build-essential pkg-config libgtk-4-dev libdbus-1-dev
just build
```

The GTK 4 runtime alone is not enough: the `gtk4` crate needs the `libgtk-4-dev` development files
(which pull in `libgraphene-1.0-dev`) at build time. `just build` checks for them first and says what is missing.

Run from the source tree (debug builds pick up the icons from `data/icons`):

```bash
just run --verbose
```

Other recipes:

```bash
just dump      # print configs and sessions seen over D-Bus, no UI
just check     # fmt, clippy, tests
just icons     # regenerate data/icons from tools/gen-icons.py
```

Install system-wide (binary, icons and desktop file):

```bash
just build                 # as your user
sudo just install          # only copies files; PREFIX=/usr/local by default, DESTDIR is honoured
```

On GNOME you need the *AppIndicator and KStatusNotifierItem Support* extension (Ubuntu ships it enabled).

## Releasing

`.github/workflows/release.yml` builds the `.deb` on Ubuntu 24.04 and publishes it as a GitHub release
whenever a `v*` tag is pushed. The tag must match `version` in `Cargo.toml`.

```bash
# bump version in Cargo.toml, commit, then:
just release      # tags v<version> and pushes the tag
```

`just deb` builds the same package locally into `target/debian/`. Running the workflow by hand
(Actions → *Release .deb* → *Run workflow*) builds the package as a downloadable artifact without
publishing a release.

## Icons

The icons are an original design: a shield with a keyhole in an orange/navy palette, plus status badges.
They are generated by `tools/gen-icons.py` (`just icons`).
